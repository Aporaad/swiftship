# تنفيذ ترحيل الحسابات المرتبطة يدويًا

نفّذ الملفين التاليين بالترتيب داخل **Supabase Dashboard → SQL Editor** لمشروع SwiftShip. لا تتضمن الأوامر حذفًا للطلبات أو الشحنات أو الكيانات الحالية؛ فهي تضيف الربط ثم تنشئ الحسابات الناقصة وتفرض العلاقات.

| الترتيب | الملف | الأثر |
|---:|---|---|
| 1 | `202608230200_link_sources_shipping_assets_financial_accounts.sql` | يضيف `account_id`، ينشئ الحسابات المفقودة، يربط البيانات السابقة، ينشئ FK ومشغلات الإنشاء التلقائي. |
| 2 | `202608230200_verify_linked_financial_accounts.sql` | يتحقق من الحسابات والروابط والمشغلات ويعرض أي صف غير مرتبط. |

## سياسة الأقسام والأرقام المحاسبية المطبقة

| الكيان | القسم | نوع الحساب | صيغة الرقم الفرعي |
|---|---:|---|---|
| مصدر طلب أو مورد | `2140` | التزام | `2140-0001` وما بعده |
| شركة شحن أو ناقل | `2150` | التزام | `2150-0001` وما بعده |
| مركبات ومعدات لوجستية | `1210` | أصل | `1210-0001` وما بعده |
| أجهزة تفتيش ومستودعات | `1220` | أصل | `1220-0001` وما بعده |
| تجهيزات مكتبية | `1230` | أصل | `1230-0001` وما بعده |
| حواسيب وتقنية | `1240` | أصل | `1240-0001` وما بعده |
| أصول ومعدات أخرى | `1250` | أصل | `1250-0001` وما بعده |

> **ملاحظة محاسبية:** عوملت المصادر وشركات الشحن كذمم دائنة تشغيلية، وعوملت الأصول الثابتة كأصول. هذه هي السياسة التي سيعرضها دليل الحسابات في التطبيق. إذا كان دليل الحسابات المعتمد لديكم يستخدم أقسامًا مغايرة، توقف قبل التنفيذ وأرسل لي الأقسام البديلة لتعديل الترحيل دون إعادة ترقيم قائمة الحسابات الحالية.

بعد التنفيذ، يجب أن تعرض استعلامات التحقق صفر صفوف في أقسام **Safety checks**، وأن تظهر ثلاثة قيود FK وثلاثة مشغلات تلقائية. أرسل لي ناتجها أو رسالة الخطأ كاملة لإتمام التحقق وتحديث نقطة الاستعادة.

### الاختبار الفاشل

`server/supabaseReadOnlyVerification.test.ts` فشل في اختبار التحقق من 18 seed لفئات الأصناف بسبب `TimeoutError` عند طلب REST، بينما نجحت الاختبارات الأخرى داخل الملف المتعلقة بالحسابات المرتبطة وعرضها. يصنف هذا كـ **Integration/Environment blocker** يحتاج إعادة اختبار اتصال Supabase، وليس فشلاً مؤكداً في منطق التطبيق.

### تحذيرات البناء المسجلة

1. `src/lib/supabase-adapter.ts` مستورد ديناميكياً وثابتاً في عدد كبير من الصفحات والخدمات؛ وهذا يؤكد أن Gateway boundary غير موجود بعد.
2. حجم chunk الرئيسي يقارب 3.46 MB بعد minification ويحتاج معالجة لاحقة، وليس ضمن إصلاح العقود الحالي.
3. استخدام `import.meta` داخل build CJS يسبب تحذيرات في `server.ts` و`loadEnv.ts` ويجب إدراجه في سجل Server Split.

## 3. حالة التشغيل الحالية

- المشروع React/Vite/TypeScript مع Express وElectron.
- `alx_api` موجود كمجلد يحتوي خطة إنشاء، وليس تطبيق API قابل للتشغيل.
- `server.ts` هو نقطة تشغيل كبيرة تجمع الخادم والتوافق والمصادقة والـ Realtime والعمليات الخلفية.
- توجد `src/pages` و`src/components` و`src/services` و`src/lib` و`server` و`supabase/migrations`.
- يوجد `alx_web` كمشروع مستقل.
- لا يوجد مجلد `tests` جذري؛ الاختبارات موزعة داخل `server` و`src`.
- توجد ملفات `.bak` يجب ألا تستخدم كمراجع تشغيل.

## 4. قواعد baseline

1. تعتمد نتائج Windows الأصلي كمرجع التشغيل الأساسي، مع إبقاء فشل اختبار REST مسجلاً كـ blocker بيئي.
2. لا تتم إضافة Feature جديدة تستورد Supabase مباشرة إلى صفحة جديدة.
3. لا يتم تنفيذ SQL جديد خارج Migration موثق ومراجع.
4. كل تغيير لاحق يقارن بهذا الـ commit وبهذا التقرير.
5. لا تحفظ مفاتيح أو محتوى `.env` في التقارير.
6. لا تعتبر تحذيرات build سبباً لتغيير معماري عشوائي؛ تسجل وتدخل في المرحلة المناسبة.

## 5. قرار المرحلة

تم اعتماد Baseline البرمجي من Windows بنجاح جزئي: `check` و`build` ناجحان، والاختبارات ناجحة باستثناء تحقق REST واحد انتهى بمهلة، مع 3 اختبارات متخطاة. قبل إغلاق هذا العائق يجب إعادة اختبار `server/supabaseReadOnlyVerification.test.ts` بعد التحقق من اتصال Supabase.

بعد ذلك انتقلت الخطة إلى إنشاء `Data Access Map`، قبل بناء Canonical Contracts، حتى لا يتم تعريف DTO أو Gateway دون معرفة الجداول والعمليات والآثار الجانبية الفعلية.

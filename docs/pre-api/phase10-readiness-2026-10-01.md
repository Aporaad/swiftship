## ترتيب البدء المقترح

1. راجع مواضع خيارات العملات الـ21 يدويًا، ووسّم كل ظهور بأنه اختيار واجهة أو تحويل/lookup أو قيمة تقريرية؛ احتفظ بعينات من العربية والإنجليزية والعملات الخاملة.
2. اختر عقدًا ضيقًا واحدًا لحقول العملة فقط إذا بقيت ثلاثة مستهلكات متكافئة على الأقل بعد التصنيف. لا تغيّر سلوك قواعد الحسابات المرجعية أو اختيار العملة الافتراضية.
3. أضف اختبار توافق للمكوّن/العقد قبل نقل المستهلكين؛ اختبر قيم `id` مقابل `code`، العملة المحددة، حالة القائمة الفارغة، اتجاه/ترجمة التسمية، وحالة القراءة فقط إذا كانت ضمن العقد.
4. انقل ثلاثة مستهلكين متشابهين أولًا، ثم شغّل `npm run check`, الاختبارات، والبناء، وافحص الفرق بصريًا قبل توسيع النطاق.
5. قيّم عرض الأموال بعد ذلك؛ افصل تنسيق النص عن تحويل العملات، ولا تخلط عرض الشاشة مع CSV/PDF والطباعة ما لم يثبت تطابقها.
6. افحص استعمال `ConfirmModal` القائم ثم الجداول؛ استخرج أصغر primitive يكرر سلوكًا متطابقًا، لا واجهة عامة ذات عشرات الخيارات.

# تطبيق يدوي لترحيل فئات الأصناف

نفّذ الملفين المرفقين بالترتيب داخل **Supabase Dashboard → SQL Editor** للمشروع `ejrojwbbflzchasvgexr`. لا يحتوي أي منهما على أسرار أو أوامر لحذف بيانات الطلبات أو الشحنات.

| الترتيب | الملف | الإجراء المتوقع |
|---:|---|---|
| 1 | `202608230130_create_items_category_and_shipment_fees.sql` | ينشئ `items_category`، يضيف حقول الفئة والرسوم، ينشئ علاقات FK، ويضيف 18 فئة أولية. |
| 2 | `202608230130_verify_items_category_and_shipment_fees.sql` | يراجع عدد الفئات والأعمدة والعلاقات بعد التنفيذ. |

> **تنبيه:** الرسوم الأولية لكل كرتون تساوي `0` عمدًا. عدّلها من تبويبة فئات الأصناف أو من قاعدة البيانات فقط بعد اعتماد القيم من الجهة المختصة؛ لا تمثل هذه البذور معدلات جمركية أو ضريبية رسمية.

بعد تنفيذ الملف الأول بنجاح، نفّذ ملف التحقق. يجب أن يعرض الاستعلام الأول `category_count = 18`، وأن يعرض استعلام العلاقات قيدي `products_item_category_id_fkey` و`shipments_content_category_id_fkey`.

إذا ظهر خطأ أثناء إنشاء قيد FK، لا تحذف أي بيانات. انسخ رسالة الخطأ الكاملة وأرسلها لي لأعطيك استعلام تشخيص غير هدّام يتعامل مع القيم المرجعية الموجودة.

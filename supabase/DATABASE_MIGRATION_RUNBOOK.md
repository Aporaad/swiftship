تم تنفيذ مرحلة قراءة فقط بتاريخ 2026-09-27 على مشروع Supabase `ejrojwbbflzchasvgexr`.

- عدد الجداول الحية: 51.
- سجل الهجرات الحي يتوقف عند `20260909190727`.

- لم يتم تطبيق أي Migration في هذه المرحلة.

## قاعدة إيقاف إلزامية

لا تطبق الهجرات المحلية `202609160001` إلى `202609170002` كما هي. بعضها يعيد تسمية أعمدة ومفاتيح ويحذف أعمدة أو قيوداً، كما أن بعضها يفترض مخططاً مختلفاً عن المخطط الحي. يجب إعادة صياغتها بعد مقارنة كاملة مع الحالة الحية.

## مراحل التنفيذ

### المرحلة A — القراءة والجرد

- تثبيت نسخة `DATABASE_SCHEMA.md` من المخطط الحي.
- جرد مفاتيح `data` وأنواعها وعدد تكرارها.
- جرد الحقول المركبة.
- جرد الحسابات والأسماء والتعارضات.
- حفظ النتائج في خرائط الترحيل والتعارضات.

### المرحلة B — مراجعة الخرائط

يجب مراجعة الملفات التالية قبل أي DDL:

- `DATABASE_FIELD_MIGRATION_MAP.md`
- `DATABASE_DATA_CONFLICTS.md`
- `DATABASE_NAME_NORMALIZATION_MAP.md`
- `DATABASE_ACCOUNT_REFERENCE_MAP.md`

ويجب إكمال الجرد الصفّي للحقول المرشحة قبل اعتماد الخريطة النهائية.

### المرحلة C — إضافة البنية دون حذف

- إضافة الأعمدة الجديدة Nullable فقط.
- إضافة القيود والفهارس بعد فحص البيانات.
- عدم حذف `data` أو الأعمدة القديمة.
- عدم إعادة تسمية Primary Keys في نفس Migration.

### المرحلة D — Backfill محدود

- تنفيذ كل جدول في Migration منفصلة أو معاملة واضحة.
- حفظ عدد الصفوف قبل وبعد.
- إيقاف العملية عند أي اختلاف في العدد أو القيم.
- عدم Backfill لـ `portal_users` أو الأسرار أو الحقول المركبة دون قواعد خاصة.

### المرحلة E — تحقق

- مقارنة counts والمعرفات والقيم.
- اختبار العلاقات وForeign Keys.
- اختبار النظام المحلي.
- إعادة توليد `DATABASE_SCHEMA.md`.
- تشغيل فحوص الأنواع والاختبارات.

### المرحلة F — إيقاف الكتابة القديمة

بعد نجاح التحقق فقط، يمنع التطبيق من كتابة المفاتيح القديمة إلى `data`.

### المرحلة G — الحذف وإعادة التسمية

مرحلة مستقلة لاحقة تتطلب:

- نسخة احتياطية.
- تقرير أثر كامل.
- Migration منفصلة لكل نوع تغيير.
- تأكيد مستقل قبل الحذف الدائم.

## لا ينفذ حالياً

- تفعيل RLS على جميع الجداول دون سياسات مصممة.
- حذف `data`.
- حذف الحقول المالية القديمة.
- إعادة تسمية PK/FK.
- تعديل `alx_web`.
- حذف بيانات المستخدمين أو السجلات المالية.
